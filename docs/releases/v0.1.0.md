# v0.1.0 — T-Embed CC1101 experimental snapshot

First packaged release of this independent Momentum-style ESP32 fork.
**Only LilyGo T-Embed CC1101 (ESP32-S3, 16 MB) is supported.**
This is not an official Momentum/Flipper Devices firmware release.

## Included

- Momentum boot screen, dedicated customization menu and nine main-menu styles.
- Encoder-operated Control Center, asset-pack support and desktop/Passport customization.
- PIN/keypad locking, dimmed lock screen and configurable locked USB/BLE RPC access.
- USB U2F, Bad KB with USB/BLE transport, qFlipper bridge and USB SD-card storage.
- Reorganized system settings, clock/alarm, LED controls and port-specific About.
- ESP32 application-loader compatibility changes and the prepared SD distribution.
- Web-Filesystem authentication/path protections and updater TLS/lifetime hardening.

Firmware binaries are the successful ESP-IDF 5.4.1 T-Embed security build from
2026-10-16 (application size: 3,652,080 bytes). Its firmware source is preserved
in commit `43bb38f4c37e50a299c6eca4f522b0923856861c`; this release adds README,
device photos and packaging documentation without changing the firmware source.
The image retains the inherited internal project version `2.0.0`; `v0.1.0` is
the release version of this fork. This build has not been flashed or hardware
retested as part of release packaging.

## Downloads and full-install offsets

| Asset | Hex offset / use |
|---|---|
| `bootloader.bin` | `0x0` |
| `partition-table.bin` | `0x8000` |
| `furi_esp32.bin` | `0x10000` |
| `ota_data_initial.bin` | `0xBF0000` |
| `sdcard.zip` | Extract contents to the root of a FAT32 SD card |

Flash settings: **ESP32-S3, 16 MB, DIO, 80 MHz**. Close qFlipper and any other
USB clients, enter firmware-download mode and select your actual serial port.

Example for esptool 4.x (included with ESP-IDF 5.4.1):

```sh
python -m esptool --chip esp32s3 --port COM8 --baud 460800 write_flash --flash_mode dio --flash_size 16MB --flash_freq 80m 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 furi_esp32.bin 0xBF0000 ota_data_initial.bin
```

These are full serial-install offsets for this partition table, not ordinary
in-app OTA instructions. Do not put OTA metadata at `0x10000`. Do not overwrite
it during a normal in-app update. Back up important data; erasing all flash
destroys device settings, pairing and software U2F credentials.

For SD setup, copy all extracted folders, including `apps` and `apps_assets`.
Do not copy an extra enclosing `sdcard` folder. Merge carefully with existing data.
The provided FAP applications are ESP32 builds, not universally compatible with
all Flipper applications. Individual app limitations remain.

## Important limitations

- Experimental software U2F has no secure element. Keep another recovery method.
- Web-Filesystem is authenticated but uses unencrypted HTTP; use a trusted network.
- In-device network firmware/SD downloads remain disabled, including after this release.
- ESP-IDF 5.4.1 still requires a security-update review before public release.
- Asset-pack rendering and hardware-dependent functions may differ from Momentum.
- Use wireless/HID functionality only with permission.

See the repository README, SECURITY.md and SECURITY-REVIEW.md for details.
